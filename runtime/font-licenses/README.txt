Tour Studio bundles variable Latin font files distributed by Fontsource.
Each family retains its original copyright and license in the adjacent file.
These notices ship with both the application and standalone tour exports.

Source packages: https://github.com/fontsource/fontsource
Documentation: https://fontsource.org/docs/getting-started/install
Families: Inter, Manrope, DM Sans, Playfair Display, JetBrains Mono, Roboto,
Open Sans, Montserrat, Nunito Sans, Oswald, Raleway, Space Grotesk, Lora,
Merriweather, Source Serif 4.
